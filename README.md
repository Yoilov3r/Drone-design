# X9 工业四旋翼三维演示

> **项目声明**：本项目是用于结构展示与飞行可视化的 Three.js 交互演示，不是真实飞控软件、CAD 数字孪生、CFD/FEA 工具或适航认证产品。模型与仿真参数为合理抽象，不可直接用于真机设计、制造、性能承诺或实际飞行决策。

基于 Three.js 的工业四旋翼交互演示。模型包含碳纤维机身、折叠臂、双电池、飞控与任务计算机、RTK 天线、电机与 21 英寸折叠桨、三轴云台和六向感知模组，并提供可循环的飞行仿真与工程视图。

## 启动

需要 Node.js 20 或更高版本，以及 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173/`。

生产构建：

```bash
pnpm typecheck
pnpm build
pnpm preview
```

## 操作

- 鼠标拖动或单指滑动：旋转观察。
- 滚轮或双指缩放：拉近查看结构。
- 点击模型部件、右侧热点或左侧部件索引：聚焦该部件。
- `飞行`：播放 28 秒循环任务，包含待机、起飞、悬停、航点、抗风、返航和降落。
- `爆炸`：查看主要装配层级；底部滑块可连续调节展开程度。
- `剖切`：观察机身、电机、电池与内部计算硬件的截面。
- `感知`：显示旋翼气流、动力路径、信号链路和传感器覆盖提示。
- 风场按钮：切换无风、约 8 m/s 侧风和阵风扰动。
- 时间轴：拖动到任意阶段；播放按钮和空格键控制暂停。
- `镜头`：重新对准当前部件；`复位`：恢复初始飞行、风场和视图。

## 仿真说明

飞行演示采用面向可视化教学的双环刚体模型：

- 位置控制环生成期望加速度，姿态控制环跟踪倾角和角速度。
- 总推力按竖直加速度需求和倾角补偿计算，再分配到四个电机。
- 电机转速由推力系数、空气密度和桨盘直径反算。
- 旋翼功率使用动量理论、品质因数与驱动效率估算。
- 阻力按动压和等效阻力面积计算，风场作为相对气流输入。
- 电池能量根据瞬时电功率积分，遥测显示惯导姿态、高度、速度、RPM、推力和功率。

主要参数位于 `src/drone/drone.ts`：整机质量 6.5 kg、对角轴距 0.9 m、21 英寸桨、双 12S 电池 526 Wh、控制子步长 4 ms。参数与几何关系保持同一尺度，适合结构讲解和飞行动作演示。

## 精度边界

这不是厂商 CAD、数字孪生、CFD/FEA 或适航认证工具。模型依据公开的工业四旋翼构型进行合理抽象，零件内部结构、材料铺层、连接强度、真实电机效率、桨叶气动弹性、飞控固件参数和传感器噪声均未按具体产品标定。仿真用于解释力和运动关系，不能用于设计校核、载荷计算、性能承诺或真实飞行决策。
